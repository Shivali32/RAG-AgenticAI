# Multimodal AI & Application Frameworks

This directory features multimodal applications integrating vision, speech processing, audio generation, and image generation using foundation models and interactive user interfaces.

* **Key Technologies & Tools:** Python, OpenAI Whisper, OpenAI DALL-E, IBM Watsonx AI, Mixtral, gTTS, LangChain, Gradio

---

## 1. Computer Vision & Image Generation (`Build an Image Captioning System with watsonx and Granite.ipynb`, `DALL E Image generation Guide for Beginners.ipynb`, `style-finder.pdf`, `style-finder.tar`)
Focuses on visual processing, automated image understanding, and prompt-driven image generation.

* **Image Captioning:** Utilizing IBM Watsonx and Granite models to analyze visual inputs and generate detailed descriptive metadata.
* **Image Generation:** Interfacing with OpenAI DALL-E APIs to transform text prompts into synthetic image assets.
* **Visual Style Search:** Processing and categorizing images based on visual features and style attributes.

---

## 2. Speech, Audio, & Conversational Applications (`Build a Meeting Assistant with Whisper, LangChain, & Gradio.pdf`, `Build a Meeting Assistant with Whisper, LangChain, & Gradio.tar`, `Use Mixtral and gTTS to create your personal storyteller.ipynb`, `cal_coach_app.tar`)
Focuses on audio processing, speech recognition, text-to-speech synthesis, and interactive assistant applications.

* **Audio Transcription & Summarization:** Transcribing recorded audio using OpenAI Whisper, followed by LangChain-driven summary and action-item generation.
* **Text-to-Speech Processing:** Generating custom narrative audio by combining text generation models (Mixtral) with Google Text-to-Speech (`gTTS`).
* **Interactive Web Assistants:** Deploying multimodal applications with Gradio frontends for real-time user audio inputs, file uploads, and contextual recommendations.
