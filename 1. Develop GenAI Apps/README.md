# Develop GenAI Apps

This directory contains implementation notebooks focusing on building generative AI applications using prompt engineering, context framing, and the LangChain framework.

---

## 1. In-Context Learning and Prompt Templates (`In-Context Learning and Prompt Templates-v3-GenAIcourse.ipynb`)
Focuses on prompt engineering techniques and structured prompt formatting to control model output behavior.

* **Prompt Structuring:** Creation and management of dynamic prompts using custom templates.
* **In-Context Learning:** Implementation of Zero-Shot, One-Shot, and Few-Shot prompting techniques to improve task completion accuracy.
* **Output Formatting:** Framing contexts to guide Large Language Models (LLMs) towards standardized responses.

---

## 2. Build Smarter AI Apps: Empower LLMs with LangChain (`Build Smarter AI Apps- Empower LLMs with LangChain-v3-GenAIcourse.ipynb`)
Demonstrates the integration of LangChain to construct modular LLM applications, manage state, and build multi-step operational chains.

* **LangChain Foundations:** Initializing LLM wrappers, model parameters, and interface components.
* **Prompt Engineering Integration:** Connecting dynamic `PromptTemplates` with language models.
* **Sequential Chains:** Linking multiple components together to process inputs through multi-stage logic pipelines.
* **Memory & State Management:** Implementing conversation history mechanisms for contextual interactions.
